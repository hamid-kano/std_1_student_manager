# صفحة العلامات (`grades`)

---

## حالات الاستخدام

### UC-01: إضافة علامة
**الحقول:**
| الحقل | الوصف | ملاحظة |
|-------|-------|--------|
| الرقم الجامعي | للبحث عن الطالب | مطلوب |
| المادة | اسم المادة | مطلوب |
| العلامة | 0 - 100 | مطلوب |
| القسم | اختياري | يُأخذ من بيانات الطالب إذا فارغ |
| السنة | 1-4 | مطلوب |
| الفصل | أول/ثاني | مطلوب |

**المنطق:**
1. يبحث عن الطالب بالرقم الجامعي
2. إذا لم يجده → flash error "الرقم الجامعي غير موجود"
3. يحفظ `student_id` (وليس الرقم الجامعي) في جدول grades

---

### UC-02: عرض العلامات
- تُعرض مجمّعة حسب الطالب
- كل طالب له جدول مستقل بمواده
- يُحسب المعدل تلقائياً: `SUM(grades) / COUNT(grades)`
- العلامة أقل من 50 تظهر بالأحمر، أكبر أو يساوي 50 بالأخضر

---

### UC-03: البحث والفلتر
| Parameter | الوصف |
|-----------|-------|
| `q` | بحث بالاسم أو الرقم الجامعي |
| `department` | فلتر بالقسم |

---

### UC-04: تعديل علامة
1. أيقونة القلم تفتح Modal
2. يمكن تعديل اسم المادة والعلامة
3. POST → `GradeController@update`

---

### UC-05: حذف علامة
- حذف سجل علامة واحدة فقط
- لا يؤثر على باقي علامات الطالب

---

## حساب المعدل (في الـ View)

```php
$sum = array_sum(array_column($student['grades'], 'grade'));
$avg = count($student['grades']) > 0
     ? round($sum / count($student['grades']), 2)
     : 0;
```
