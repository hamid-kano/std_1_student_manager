# الصفحات الأكاديمية

## الكليات (`faculties`)

### UC-01: إضافة كلية
- الحقول: اسم الكلية (مطلوب)، اسم العميد (اختياري)
- POST → `FacultyController@store`

### UC-02: تعديل كلية
- Modal يفتح بالبيانات الحالية
- POST → `FacultyController@update`

### UC-03: حذف كلية
- تأكيد قبل الحذف
- الأقسام المرتبطة: `faculty_id` يصبح NULL (SET NULL)

---

## الأقسام (`departments`)

### UC-01: إضافة قسم
- الحقول: اسم القسم (مطلوب)، الكلية (select من قاعدة البيانات)
- POST → `DepartmentController@store`

### UC-02: تعديل قسم
- يمكن تغيير الاسم والكلية المرتبطة

### UC-03: حذف قسم
- المقررات المرتبطة تُحذف تلقائياً (CASCADE)

---

## المقررات (`courses`)

### UC-01: إضافة مقرر
- الحقول: القسم، اسم المادة، السنة، الفصل (كلها مطلوبة)
- POST → `CourseController@store`

### UC-02: عرض المقررات
تُعرض هرمياً:
```
قسم
  └─ سنة
       └─ فصل
            └─ [مادة 1] [مادة 2] ...
```

### UC-03: حذف مقرر
- زر X بجانب كل مادة مباشرة (بدون Modal)

---

## المدرسون (`staff`)

### UC-01: إضافة مدرس
- الحقول: الاسم (مطلوب)، جامعة التخرج، الخبرات
- POST → `StaffController@store`

### UC-02: تعديل مدرس
- Modal مع الحقول الثلاثة

### UC-03: حذف مدرس
- حذف مباشر بعد التأكيد

---

## الصفحة الرئيسية (`dashboard`)

تعرض إحصائيات حية من قاعدة البيانات:

| البطاقة | الاستعلام |
|---------|-----------|
| إجمالي الطلاب | `SELECT COUNT(*) FROM students` |
| المنتظمون | `WHERE status='active'` |
| المدرسون | `SELECT COUNT(*) FROM staff` |
| الأقسام | `SELECT COUNT(*) FROM departments` |
| المقررات | `SELECT COUNT(*) FROM courses` |
| العلامات | `SELECT COUNT(*) FROM grades` |

وروابط سريعة للصفحات الأكثر استخداماً.
