# صفحة تسجيل الدخول

**المسار:** `/?page=login` أو مباشرة عند عدم وجود جلسة

---

## حالات الاستخدام

### UC-01: تسجيل دخول ناجح
1. المستخدم يدخل `admin` / `admin123`
2. النظام يتحقق من قاعدة البيانات
3. يُنشئ جلسة ويوجّه لـ `/?page=dashboard`

### UC-02: بيانات خاطئة
1. المستخدم يدخل بيانات غير صحيحة
2. تظهر رسالة: "اسم المستخدم أو كلمة المرور غير صحيحة"
3. يبقى في صفحة الدخول

### UC-03: تسجيل الخروج
1. المستخدم يضغط "خروج" في الهيدر
2. POST إلى router مع `action=logout`
3. تُدمَّر الجلسة ويُوجَّه لصفحة الدخول

### UC-04: محاولة الوصول بدون جلسة
1. المستخدم يفتح أي صفحة مباشرة
2. `Session::requireLogin()` يكتشف غياب الجلسة
3. redirect تلقائي لـ `/?page=login`

---

## الأمان
- كلمات المرور مشفرة بـ `bcrypt` (PASSWORD_DEFAULT)
- الجلسة تُخزَّن server-side في `$_SESSION`
- لا تُخزَّن كلمة المرور أبداً في الجلسة
