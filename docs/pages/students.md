# صفحات الطلاب

## صفحتان مترابطتان:
- `/?page=register` — تسجيل طالب جديد
- `/?page=students` — عرض وإدارة الطلاب

---

## التسجيل الجامعي (`register`)

### UC-01: تسجيل طالب جديد
**الحقول المطلوبة:** الرقم الجامعي، الاسم، الكلية، القسم
**الحقول الاختيارية:** مكان الولادة، تاريخ الميلاد، العنوان، الهاتف، اسم الأم، اسم الأب، الجنس، الصورة

**التحقق:**
- الرقم الجامعي والاسم لا يمكن أن يكونا فارغين
- الرقم الجامعي يجب أن يكون فريداً (UNIQUE في قاعدة البيانات)

**رفع الصورة:**
- تُحفظ في `assets/uploads/students/`
- اسم الملف: `student_[uniqid].[ext]`
- المسار يُخزَّن في حقل `image`

**بعد النجاح:** flash message + redirect لـ `/?page=students`

---

## قائمة الطلاب (`students`)

### UC-02: البحث والفلترة
البحث يعمل عبر GET parameters:

| Parameter | الوصف | مثال |
|-----------|-------|-------|
| `q` | بحث بالاسم أو الرقم الجامعي | `?q=أحمد` |
| `department` | فلتر بالقسم | `?department=هندسة الحاسوب` |
| `status` | فلتر بالحالة | `?status=active` |

يمكن دمجها: `?q=أحمد&department=هندسة الحاسوب&status=active`

---

### UC-03: تغيير حالة الطالب
- زر "منتظم/موقوف" في كل صف
- POST مع `action=toggle_status` و `id`
- يبدّل الحالة بـ SQL مباشر بدون قراءة مسبقة

---

### UC-04: تعديل بيانات الطالب
1. المستخدم يضغط أيقونة القلم
2. Modal يفتح مع البيانات الحالية (JavaScript)
3. المستخدم يعدّل ويضغط "حفظ"
4. POST مع `action=update`
5. يمكن تغيير الصورة من نفس الـ Modal

---

### UC-05: حذف طالب
1. المستخدم يضغط أيقونة الحذف
2. `confirm()` يطلب التأكيد
3. POST مع `action=delete`
4. يُحذف الطالب مع كل علاماته وغياباته (CASCADE)

---
