# صفحة البطاقات الجامعية (`cards`)

> هذه الصفحة تعمل بالكامل client-side (JavaScript + localStorage) — لا تتفاعل مع قاعدة البيانات.

---

## حالات الاستخدام

### UC-01: إنشاء بطاقة
**الحقول:**
| الحقل | الوصف |
|-------|-------|
| اسم الجامعة | نص |
| شعار الجامعة | صورة (file input) |
| اسم الطالب | نص |
| الرقم الجامعي | نص |
| اسم الأم | نص |
| مكان وتاريخ الولادة | نص |
| الكلية | نص |
| القسم | نص |
| تاريخ البطاقة | date |
| صورة الطالب | صورة (مطلوبة) |

**المنطق:**
1. `FileReader` يحوّل الصور لـ Base64
2. تُبنى البطاقة كـ HTML ديناميكي
3. تُحفظ في `localStorage` تلقائياً

---

### UC-02: البحث في البطاقات
- بحث فوري (onkeyup) بالاسم أو الرقم الجامعي
- يخفي/يظهر البطاقات بـ `display:none/block`

---

### UC-03: طباعة بطاقة
1. المستخدم يضغط "طباعة"
2. تُفتح نافذة جديدة بـ `window.open()`
3. تُطبع البطاقة بعد 500ms (لضمان تحميل الصور)
4. أزرار التحكم مخفية في الطباعة بـ CSS

---

### UC-04: حذف بطاقة
- `btn.closest('.student-card').remove()`
- يُحدَّث `localStorage` تلقائياً

---

## التخزين (localStorage)

```javascript
// حفظ
localStorage.setItem('CardsPage', document.getElementById('cardsOutput').innerHTML);

// تحميل عند فتح الصفحة
const saved = localStorage.getItem('CardsPage');
if (saved) container.innerHTML = saved;
```

> **تنبيه:** البيانات مرتبطة بالمتصفح والجهاز — لا تُزامَن بين أجهزة مختلفة.
> للمرحلة القادمة: حفظ البطاقات في قاعدة البيانات.
